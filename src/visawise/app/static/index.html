Reranking does two things at once. We measured them apart.

Reranking — reorder

rerank→8 vs no rerank: the same 8 passages, reordered by a cross-encoder. Hit-rate is identical (nothing new retrieved), but MRR climbs 0.798 → 0.838. The reranker earns its place by ranking the right passage higher — cleanly, with no judge in the loop.

Reranking — truncate

rerank→4 vs rerank→8: keeping only the top 4 passages instead of 8 is what nudges hit-rate down (0.885 → 0.865) — that, not the reranking, is the recall cost. In exchange: higher context precision and half the input tokens, so a free 8B model answers in ~4s.

The uncontrolled version of this comparison couldn't tell these three effects apart. The controlled ladder can — and it changes what "reranking helps" means.

Four free models entered. One was fast, safe, and free.

The free 8B (original default)

Fast and $0 — but it leaked its own system prompt, answered out-of-scope questions, and gave confident advice where it should abstain: 2/15 on the safety slices, and a guardrail prompt tanked its answer quality instead of helping.

Gemini 3.1 Flash-Lite (chosen)

14/15 safety, 0.92 faithfulness, ~2.5s, still $0. gpt-oss-20b matched it on safety but ran at 31s and hit a daily token cap; Llama-4-Scout was fast but 5/15. Only Flash-Lite cleared all three bars.

The model is one flag in the config — and the eval harness, not a hunch, chose it, after the free tiers of the "better" models turned out to be quota mirages.

Safety isn't a vibe. We slice it — and tuned a guardrail against it.

Six behaviours, measured

A human-reviewed set probes what synthetic questions can't: out-of-corpus abstention, prompt-injection resistance, and high-risk qualification — graded by an independent judge, on a set held out from prompt tuning.

Guardrail prompt v1 → v4

v2 over-hedged (answer quality collapsed); v3's blunt binary broke refusals; v4's explicit precedence — refuse → qualify → answer — restored both. Result: 14/15 (out-of-corpus 5/5, high-risk 5/5, injection 4/5).

Tuned on a separate dev split, measured once on the held-out set — so the 14/15 is an honest read, not a number fit to its own test.
